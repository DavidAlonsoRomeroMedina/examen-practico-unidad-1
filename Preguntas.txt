1. La primera diferencia es que la API Rest utiliza muchos endpoints mientras que un servidor GraphQL utiliza solo uno. La segunda diferencia es que cuando haces una consulta con API REST su respuesta siempre está completa y estructurada, es decir que muchas veces te da más de lo que solicitaste, esto pasa porque las estructuras ya están definidas, mientras que con servidores GraphQL te da solo lo que le pides.

2. Conviene más usar REST cuando lo que queremos buscar es información completa con una sola busqueda, pro ejemplo si queremos ver un menú en un restaurante, nos muestran todos los platillos, todas las bebidas, el precio, los postres, etc. Es decir, nosotros buscamos por ejemplo. "Menú" y ya nos aparece todo. En cambio si nosotros queremos buscar cosas más especificas de diferentes objetos ahí conviene más usar GraphQL, por ejemplo queremos los nombres de todos los estudiantes que nacieron después del 2005, entonces buscamos nombres de estudiantes, con la condicion de que hayan nacido después del 20005.

3. Una imagen es como una plantilla de solo lectura, es lo que contiene el código, las dependencias, etc. pero el contenedor es la instancia que le da vida a esa imagen, en este caso docker es el que lee el archivo y construye la imagen que luego manda al contenedor para darle vida.

4. Docker compose corre aplicaciones con multiples contenedores, en lugar de escribir comandos en la terminal para levantar cada contenedor uno por uno, docker compose los define todos dentro de un solo archivo y al momento de levantarlos los levanta a todos. y el primer 8000 es el puerto de tu máquina y el segundo es el puerto del contenedor

5. Las laptops se guardan en MySQL y no en una lista de Python porque la lista solo existe mientras la API está encendida. Si se detiene el contenedor, esa lista se pierde. MySQL guarda los registros en la base, así que al reiniciar la API con docker compose restart api las laptops siguen ahí, incluidas las que se crearon con POST. La llave primaria id identifica de forma única a cada laptop. Por eso se puede pedir, por ejemplo, la laptop 2 y obtener solo esa, sin confundirla con otra del mismo modelo o de la misma marca.
